# The Mac Desktop fills the visitor's screen

Spec #1 kept the compact Macintosh's frame around the portfolio on large screens after the Intro. We now end the Intro by passing through the Macintosh's screen, so the visitor's whole screen becomes the Mac Desktop: Menu Bar along the top, a 1-bit pattern, and the Mac Window on it. The Macintosh itself appears only during the Intro. This matches the old Lottie's goal of entering the computer, and gives desktop visitors more room to read.
